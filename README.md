# Joker Sports ⚽👑

تطبيق ويب لمواعيد مباريات كرة القدم الأسبوعية: المواعيد بتوقيت القاهرة، القنوات المعلنة من المصدر، حالة المباراة مباشرة، والتشكيلات عندما ينشرها المصدر.

## التشغيل
موقع ثابت بلا أي بناء: يكفي نشر محتوى المستودع على GitHub Pages (الفرع الرئيسي، الجذر).

- `index.html` + `styles.css` + `app.js` + `icon.svg` — الواجهة (عربية RTL، خطوط Cairo/Tajawal مستضافة محليًا برخصة OFL).
- `matches.json` — بيانات الأسبوع الحالي، تُبنى وتُحدَّث تلقائيًا.
- `fetch_data.py` — سكربت جلب البيانات.
- `.github/workflows/update-data.yml` — تحديث يومي تلقائي (04:30 UTC) + تشغيل يدوي.

## مصادر البيانات
- **ESPN** (JSON عام بدون مفتاح): الدوريات الإسباني، الإنجليزي، الإيطالي، الألماني، الفرنسي، ودوري أبطال أوروبا — مواعيد، نتائج، قنوات معلنة (غالبًا للسوق الأمريكي)، وتشكيلات قرب المباريات.
- **TheSportsDB** (مفتاح مجاني تجريبي): الدوري المصري الممتاز — بيانات جزئية ويُشار لذلك داخل التطبيق.

## حدود معروفة (بصراحة)
- **اسم المعلق** و**جودة البث** لا تنشرهما المصادر المجانية؛ يظهران «غير معلن» بدل التخمين.
- القنوات المعروضة كما يعلنها ESPN وقد تختلف عن الناقل في مصر/المنطقة (beIN وغيرها غير مدرجة في المصدر).
- تغطية الدوري المصري محدودة وقد لا تشمل كل المباريات.
- التشكيلات تظهر فقط عندما ينشرها المصدر (عادة قرب البداية).

## التطوير محليًا
```bash
python3 fetch_data.py   # يبني data/matches.json
python3 -m http.server 8000     # ثم افتح http://localhost:8000
```

## الخصوصية والمفاتيح
لا توجد مفاتيح سرية ولا حسابات؛ كل المصادر عامة ومجانية، ولا يجمع التطبيق أي بيانات مستخدمين (التخزين المحلي يُستخدم فقط لحفظ نسخة من الجدول للعرض دون اتصال).
